# نظام إدارة مخولين مكتب النائب

تطبيق ويب (PWA) لإدارة المخولين والمهام/الطلبات في مكتب النائب، قابل للتثبيت كأيقونة على الشاشة الرئيسية لأندرويد، آيفون (iOS)، وويندوز.

## المزايا

- تسجيل دخول بحساب مستخدم وكلمة مرور، بثلاثة أدوار: **مسؤول رئيسي**، **مخوّل**، **اطلاع فقط**.
- شاشة رئيسية بثلاث بطاقات رئيسية: **المخولين**، **الطلبات**، **المتأخرة** + إحصائيات سريعة.
- إدارة المخولين مع إمكانية إضافة صورة لكل شخص.
- إضافة مهمة (طلب) عبر زر "مهام" بالحقول التالية: إسناد المهمة إلى المخوّل، التاريخ (تاريخ الاستحقاق)، إرفاق ملف، التفاصيل، اسم المكتب صاحب الطلب، عنوان المهمة.
- المخوّل يستطيع تحديد حالة المهمة: **قيد الانجاز** / **منجز** (يُسجَّل تاريخ الإنجاز تلقائياً) / **مرفوض** (مع ذكر السبب)، وإعادة رفع ملف عند إكمال المهمة.
- المهام المتأخرة تُحسب تلقائياً (مهمة "قيد الانجاز" تجاوزت تاريخ استحقاقها).
- تقارير: لكل مخوّل، لكل مكتب، وتقرير عام، مع تصدير Excel.
- حسابات اطلاع فقط (قراءة/تقارير بدون تعديل).
- أرشفة تلقائية لكل مهمة جديدة أو تحديث حالة عبر بوت تلغرام (اختياري).
- قابل للتثبيت كتطبيق (PWA) بأيقونة باللون التركوازي على أندرويد وآيفون وويندوز.

## التشغيل محلياً

يتطلب تثبيت [Node.js](https://nodejs.org) (الإصدار 18 فأعلى).

```bash
npm install
npm start
```

بعد التشغيل، افتح المتصفح على: `http://localhost:3000`

### الحساب الافتراضي عند أول تشغيل

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

**مهم جداً:** غيّر كلمة المرور فوراً من داخل التطبيق (زر "تغيير كلمة المرور" أو من صفحة إدارة الحسابات).

## إعداد بوت تلغرام للأرشفة (اختياري)

1. افتح تطبيق تلغرام وابحث عن **BotFather**.
2. أرسل له الأمر `/newbot` واتبع التعليمات لإنشاء بوت جديد، سيعطيك **توكن** (Token) شبيه بـ:
   `123456789:ABCdefGhIJKlmNoPQRstuVwxyZ`
3. أنشئ قناة أو مجموعة تلغرام خاصة بالأرشيف، وأضف البوت إليها كمشرف (Admin).
4. للحصول على **معرّف المحادثة** (Chat ID):
   - إذا كانت قناة: انشر أي رسالة فيها ثم افتح
     `https://api.telegram.org/bot<التوكن>/getUpdates` في المتصفح، وابحث عن `"chat":{"id":...}` — عادة يبدأ برقم سالب مثل `-1001234567890`.
   - أو استخدم بوت مساعد مثل `@userinfobot` / `@getidsbot` للحصول على المعرف مباشرة.
5. انسخ ملف `.env.example` إلى `.env` وعبّئ القيم:

```
TELEGRAM_BOT_TOKEN=التوكن_هنا
TELEGRAM_CHAT_ID=معرف_المحادثة_هنا
```

6. أعد تشغيل الخادم. من الآن، كل مهمة جديدة أو تحديث حالة (منجز/مرفوض/قيد الانجاز) سيُرسَل تلقائياً كنسخة أرشيفية إلى القناة.

> إذا تُركت هذه المتغيرات فارغة، يعمل التطبيق بشكل طبيعي بدون الأرشفة على تلغرام.

## النشر على الإنترنت (حتى يصبح رابطاً حقيقياً يمكن تثبيته من الهاتف)

التطبيق عبارة عن خادم Node.js عادي، ويمكن نشره مجاناً على أي من المنصات التالية:

### الخيار الأول: Render.com (موصى به، مجاني)

1. أنشئ حساباً على [render.com](https://render.com) وحسابك على GitHub.
2. ارفع مجلد المشروع إلى مستودع (repository) جديد على GitHub.
3. من لوحة Render اختر **New > Web Service** واربطه بالمستودع.
4. في الإعدادات:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. أضف متغيرات البيئة (Environment Variables) من `.env.example`: `SESSION_SECRET`, وإن رغبت `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`.
6. بعد النشر ستحصل على رابط HTTPS دائم (مثل `https://your-app.onrender.com`) — هذا الرابط هو ما يفتحه المخولون ويثبّتونه على هواتفهم.

> ملاحظة: يستخدم التطبيق قاعدة بيانات SQLite مخزّنة كملف على القرص (`data/app.db`). في الخطة المجانية من Render قد يُعاد ضبط القرص عند إعادة النشر، لذا يُفضّل تفعيل خدمة **Persistent Disk** (متوفرة برسوم بسيطة) أو الانتقال لاحقاً لقاعدة بيانات مُدارة إذا زاد حجم الاستخدام.

### الخيار الثاني: Railway.app

نفس الخطوات تقريباً: اربط المستودع، اضبط أمر البدء `npm start`، وأضف متغيرات البيئة. يوفر Railway تخزيناً دائماً (Volume) يمكن ربطه بمجلد `data/` و`public/uploads/` للحفاظ على البيانات والمرفقات بين عمليات إعادة النشر.

## تثبيت التطبيق كأيقونة على الهاتف/الويندوز

بعد نشر التطبيق والحصول على رابط HTTPS:

- **أندرويد (Chrome):** افتح الرابط، اضغط على قائمة المتصفح (⋮) ثم "إضافة إلى الشاشة الرئيسية" / "تثبيت التطبيق".
- **آيفون (Safari):** افتح الرابط، اضغط على زر المشاركة (Share) ثم "إضافة إلى الشاشة الرئيسية".
- **ويندوز (Chrome/Edge):** افتح الرابط، ستظهر أيقونة تثبيت (⊕) في شريط العنوان، اضغط عليها لتثبيت التطبيق كبرنامج مستقل بأيقونته الخاصة.

في كل الحالات ستظهر أيقونة التطبيق باللون التركوازي المُعد في هذا المشروع.

## هيكل المشروع

```
office-agents-app/
├── server/
│   ├── index.js        # الخادم الرئيسي وكل مسارات الـ API
│   ├── db.js            # تهيئة قاعدة البيانات SQLite والجداول
│   ├── auth.js           # التحقق من الجلسات والصلاحيات
│   └── telegram.js       # إرسال الأرشيف إلى بوت تلغرام
├── public/
│   ├── index.html         # واجهة التطبيق (شاشة واحدة SPA)
│   ├── app.js              # منطق الواجهة الأمامية
│   ├── styles.css           # التنسيقات (الثيم التركوازي)
│   ├── manifest.json         # إعدادات PWA
│   ├── service-worker.js      # لتفعيل التثبيت والعمل الجزئي دون اتصال
│   ├── icons/                  # أيقونات التطبيق بمقاسات مختلفة
│   └── uploads/                 # الملفات والصور المرفوعة (تُنشأ تلقائياً)
├── assets/icon.svg                # مصدر الأيقونة
├── data/app.db (يُنشأ تلقائياً)      # قاعدة البيانات
├── .env.example
└── package.json
```

## ملاحظات أمنية قبل الاستخدام الفعلي في الدائرة

- غيّر `SESSION_SECRET` في `.env` إلى نص عشوائي طويل وخاص.
- غيّر كلمة مرور الحساب الرئيسي الافتراضي فور أول تشغيل.
- يُنصح بتفعيل النسخ الاحتياطي الدوري لمجلد `data/` و`public/uploads/` لأنهما يحويان قاعدة البيانات والمرفقات.
- استضف التطبيق دائماً عبر HTTPS (المنصات المذكورة أعلاه توفر ذلك تلقائياً) لحماية كلمات المرور أثناء الإرسال.
